# DX-BT18 / BT18-T — завершение исследований (11.10.2026)

**Статус: CLOSED — NOT CERTIFIED.** Пользователь решил прекратить работу с текущими экземплярами после безрезультатных проверок. Ни физический дефект, ни контрафактность, ни конкретная микросхема не установлены.

## История аппаратных экземпляров по опыту владельца

| Поколение | Сообщённый опыт |
| --- | --- |
| Оригинальный DX-BT18 с заводской маркировкой | Отличная работа («шикарны»). |
| Ранее приобретённые копии без маркировки | Работали хуже оригиналов. |
| Нынешние немаркированные устройства, видимые как `BT18-T` | Не дали требуемой функциональности; пользователь считает их непригодными. |

Это **практические качественные наблюдения**, а не слепое сравнение одинаковых партий или измеренный коэффициент качества.

## Подтверждённые признаки нынешних образцов

- Проданы под именем DX-BT18; металлический экран без маркировки.
- Четырёхпроводное подключение: TX, RX, VCC, GND.
- На компьютере виден USB-UART CH340 на COM4 (функционирование CH340 **не подтверждает** UART Bluetooth-модуля).
- Телефон обнаруживает имя `BT18-T`.
- В практических проверках владельца получить ожидаемые AT-ответы не удалось.

## Чего мы не установили

- Модель SoC, производителя, реальную ревизию и подлинность DX-BT18.
- Действительную скорость UART и условие доступа к AT-командам.
- Работу Classic SPP или GATT; факт обнаружения имени не равен полноценному тесту.
- Возможность чтения/перезаписи прошивки и первопричину отсутствия ответов.

Оригинальные руководства DX-SMART указывают **9600 бод по умолчанию**; 115200 встречается также в условиях измерений пропускной способности. Эти значения не подтверждают фактическую конфигурацию BT18-T.

## Решение

**Текущие экземпляры больше не диагностируем, не ремонтируем и не перепрошиваем.** Справочники и инструменты сохраняются для других модулей.

Технические скрипты можно запускать обычным системным Python (`py`, `py -m pip install --user ...`), без `.venv`. Это изменение режима работы с инструментами **не меняет статус аппаратных испытаний**.
